# City Guides partner photos

One folder per venue, named by the venue slug. Drop each place's photo inside,
named to match its entry in data/top_picks.json (the `photo` field is already
filled in with the exact path).

Naming: img/cityguides/<venue-slug>/<place-slug>.jpg
Example: img/cityguides/moody-center/el-chile-cafe-y-cantina.jpg

Use the same image you run in that spot's Instagram "Best Eats" feature.
Recommended: landscape, at least 1200px wide, JPG.
If a photo is missing, the card falls back to a clean monogram, nothing breaks.
