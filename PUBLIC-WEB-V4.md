# Concerto Public Web V4

## Principle
One content system. Two presentation systems.

The public website is a brand, discovery, SEO, and conversion experience. The native app is the operational concert-night experience. Both use the same underlying Concerto data.

## Public proof used
- 532K+ Instagram views in the last 90 days
- 306K+ viewers in the last 90 days
- 97.9% of recent views from non-followers
- 78K+ content interactions in the last 90 days
- 42K+ accounts engaged in the last 90 days
- 153K Google Search impressions over 12 months

These are presented as reach/attention metrics, never as users, customers, or downloads.

## Media
Venue imagery resolves server-side through the existing Google Places photo function, with a Ticketmaster event-image fallback on the public web. Tour imagery uses the existing Ticketmaster proxy. API secrets stay server-side.
